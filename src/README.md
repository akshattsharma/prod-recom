# Product Recommendation AI

1. npm i react-router-dom react-icons
2. Copy everything in `src/` into your project's `src/` (replace index.js and App.js).
3. Copy `vercel.json` to the project root (so /history works when opened directly on Vercel).
4. npm start

Replies live in `src/replies.json`: add products, keywords and budget tiers there.
